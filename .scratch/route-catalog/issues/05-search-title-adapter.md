# 05: Układ strony i tytuły wyszukiwania

**What to build:** Wyniki wyszukiwania noszą nazwę Trasy zamiast tytułu wyciąganego z dowolnego nagłówka. Użytkownik widzi zwięzły, spójny tytuł bez sufiksu szkoły, a autor treści nie musi go ustawiać osobno przy każdej stronie.

**Blocked by:** 01: Katalog Tras i pierwszy adapter breadcrumbów.

**Status:** ready-for-agent

- [ ] Układ strony emituje tytuł wyszukiwania z katalogu Tras.
- [ ] Wycinanie sufiksu szkoły z tytułu znika; domyślnym tytułem wyszukiwania jest etykieta kanoniczna Trasy.
- [ ] Dodatkowy prop do ręcznego ustawiania tytułu wyszukiwania znika, chyba że Trasa wyraźnie zdefiniuje własny tytuł.
- [ ] Tytuł strony, metadane udostępniania i treść pozostają niezmienione.
- [ ] Build projektu przechodzi, a przegląd wyników wyszukiwania potwierdza nowe, zwięzłe tytuły.
